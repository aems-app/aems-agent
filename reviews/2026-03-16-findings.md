### 2. FIXED: required browser headers are not allowed by CORS
- Affected files: `src/aems_agent/app.py`, `src/aems_agent/routes.py`
- Verification result: `create_app()` now includes both `X-AEMS-Annotation-Contract-Version` and `X-AEMS-Delivery-Id` in `allow_headers`.

### 3. STILL VALID: replacing `submission.pdf` can still leave a stale annotated PDF in place

- Impact: if the stale annotated file cannot be deleted, it is still reused.

### 4. STILL VALID: download idempotency preserves corrupt files when `expected_size` is missing
- Affected files: `src/aems_agent/canvas_download.py`
- Verification result: unchanged. Existing `submission.pdf` is still skipped when `expected_size` is absent, even if the file is corrupt.

### 5. STILL VALID: the advertised grading bundle `v1` is only partially aligned with the app reader
- Affected files: `src/aems_agent/grading_bundle.py`, `src/aems_agent/routes.py`
- Cross-repo counterpart: `aems/src/aems/web/api/v1/canvas/grading/bundle_adapter.py` (in the main AEMS server repo)
- Verification result: the agent now emits `needs_ocr` / `has_handwriting`, and the app adapter now reads `page_number`. But the agent's `page_number` is 1-based and the app still feeds it into 0-based internal fields without normalization.
- Impact: OCR flags are fixed, but page numbering can still shift by one in local grading.
